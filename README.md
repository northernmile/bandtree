# band/tree

Search any band and explore every member, every band they've played in, and the full discography.

A single static page (`index.html`) — no build step, no server, no API keys. Data comes straight from
public APIs in the browser: MusicBrainz (primary), Wikidata, Discogs, Wikipedia, Cover Art Archive,
iTunes and Deezer.

## Run locally

```sh
python3 -m http.server 8765
```

Then open http://localhost:8765.
